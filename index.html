01 / Backup completo

Salva suas demandas, serviços, cores e documentos anexados em um arquivo JSON. Guarde-o em um local seguro.

02 / Restaurar dados

Importe um backup deste aplicativo. A restauração substitui os dados compartilhados, após sua confirmação.

03 / Planilha de demandas

Exporte uma tabela CSV para abrir no Excel ou outro editor de planilhas. Os anexos ficam no backup completo.

04 / Acesso da equipe

Cada integrante acessa este mesmo endereço com seu e-mail e senha. A administradora cadastra os acessos na aba Equipe e acesso.

Onde meus dados ficam?

Esta versão salva as demandas e os anexos no servidor compartilhado. A equipe pode somente inserir demandas. Apenas a administradora visualiza e gerencia o quadro completo. Alterações são sincronizadas automaticamente; edições simultâneas conflitantes são bloqueadas para evitar perda de dados. Faça backups regulares.

Este sistema não depende da conta ou assinatura do ChatGPT. O site fica no GitHub e os dados protegidos no seu projeto Firebase. O plano gratuito tem limites de uso, especialmente para documentos anexos.
